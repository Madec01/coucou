# Crédits

Le code du jeu (dossiers `src/`, `css/`, `tools/`, `tests/`, `index.html`) est publié sous licence MIT (voir `LICENSE`).

Toutes les œuvres ci-dessous appartiennent à leurs auteurs et sont utilisées selon leurs licences. Le site de Kenney étant inaccessible depuis l'environnement de travail, les fichiers ont été récupérés depuis un miroir GitHub des mêmes packs, dont la licence est embarquée.

- **Game Icons** (icônes de l'interface : `assets/img/ui/`) — Kenney — licence CC0 1.0 — [source](https://kenney.nl/assets/game-icons) — [miroir utilisé](https://github.com/ETdoFresh/kenney.nl)

Les billes rouge et bleue sont la bille grise du pack, recolorée par un filtre au chargement. Le ciel, la lune, la lampe, les ombres, la traînée et le graphique sont des dégradés et des tracés : aucune image n'est dessinée par le code.
