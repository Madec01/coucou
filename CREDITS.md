# Crédits

Le code du jeu (dossiers `src/`, `css/`, `tools/`, `tests/`, `index.html`) est publié sous licence MIT (voir `LICENSE`).

Toutes les œuvres ci-dessous appartiennent à leurs auteurs et sont utilisées selon leurs licences. Le site de Kenney étant inaccessible depuis l'environnement de travail, les fichiers ont été récupérés depuis un miroir GitHub des mêmes packs, dont la licence est embarquée.
